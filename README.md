# Painel de estudos

Um painel responsivo para acompanhar uma jornada de aprendizagem em desenvolvimento front-end. Este projeto também é nosso espaço de prática: ele vai evoluir junto com os assuntos estudados.

## Primeira versão

Esta etapa apresenta uma página estática construída com HTML semântico e CSS responsivo. Ainda não há interações: as tarefas, contadores e progresso são exemplos visuais.

### Como visualizar

Abra o arquivo `index.html` no navegador. Não é necessário instalar dependências.

## Trilha do projeto

1. **Fundamentos:** estrutura inicial, editor, Git e GitHub.
2. **HTML e CSS:** semântica, acessibilidade, layout e responsividade.
3. **JavaScript:** interações, tarefas e salvamento local.
4. **React:** componentes, estado e navegação.
5. **TypeScript:** tipagem e validação de dados.
6. **Projeto final:** refinamento, publicação e documentação para o portfólio.

## Tecnologias

- HTML5
- CSS3

## Próxima melhoria

Revisar juntos a estrutura HTML e os estilos, depois começar a etapa de JavaScript para permitir marcar tarefas e atualizar o progresso.
